# Wonderboot

Wonderboot es una aplicación web de viajes. Permite guardar, consultar, modificar viajes... También permite inicio de sesión, registro y ver y modificar tu perfil.

## Tecnologías

- Java 25
- Spring Boot 4.1
- Maven
- H2

## Dependencias
Este proyector requiere de una api externa para funcionar, location-api. Esta es la que devuelve los countries y cities. Sin ella, la aplicación no funcionará como debe.
